How it goes

Playsets are bolted and screwed together to stand up to years of kids, so they do not come out in one piece. We take the set apart where it stands, carry the pieces out through the gate, load the truck and pick up the hardware so nothing is left in the grass.

Some sets are anchored in concrete footings. Tell us when you ask for the estimate, and send a photo of the legs if you can, so we can plan for it.
